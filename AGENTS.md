# odm-web

Public ODM site. Git submodule of `hembrow-innovations/odm-web`.

Static HTML and CSS. No React kit. GitHub Actions allowed only for GitHub Pages.

- Commits as work packages: `<type>(<scope>): <description>` (`feat` | `fix` | `test` | `refactor` | `chore`)
- No `Co-Authored-By` lines
- Markdown: never tables. Use `- **{text}**: {text}`
- No em dashes
